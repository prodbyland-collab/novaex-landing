# NOVAX landing page

An original, responsive crypto-exchange landing page concept inspired only by the high-level dark, market-focused presentation of the supplied reference.

## Open it

Open `index.html` in a browser, or serve this folder using any static web server.

## Customize

- Change the name and headline in `index.html`.
- Adjust colors in the `:root` section of `styles.css`.
- Wire the placeholder links and buttons to real routes before production use.
